## Learned noisy and weak-signal memory
Compare fresh-trained RNN hidden24 (746params), LIF membrane hidden24 (722), and a smaller gated spike-encoded synaptic memory hidden24 (about148params). New memory has trainable threshold neurons, learned event-strength gate, write-once occupancy and persistent analog synaptic trace. It is a hybrid architecture, not conventional leaky LIF or a fully spike-only network. No true pulse times/labels at inference; gate only sees input signal strength. Training budgets/data shared; parameter/expressivity not matched.
Five seeds42–46, independent train/validation at lengths16/32/64 (64examples each). Balanced first-sign labels; second sign independent, so remembering last sign cannot solve the task. Half signal amplitudes1, half .6; noise .1/.2 balanced. Crucially signal pulses are added to noisy inputs rather than overwriting noise; final query identical. 120Adamupdates lr .01, clip1; minimum validation CE every10updates. Test512 fresh examples/condition at lengths32/96/192, amplitudes1/.6, noise .1/.2/.3. All models evaluated identically; old engineered v2 slot included as an unchanged historical control, with abstentions penalized. Optional confidence threshold chosen only on validation for>=95% accepted accuracy; report raw accuracy, coverage and accepted accuracy together. Save/reproduce states. Missing-first/no-events are separate diagnostic rejection tests, not binary class accuracy. No test-based model choice or energy claim.

## Ontology-aware unfamiliar-intent routing
Use official CLINC domain/intent names as explicit supported-function descriptions, including names of held-out intents. This supplies taxonomy knowledge: it tests routing to named categories without labelled training examples, not discovering entirely unnamed intents. Construct descriptor strings from intent names and predeclared domain descriptions; encode classification-prefixed strings using frozen installed Nomic. Use existing independently encoded query cache, no new learned preprocessing on test. All150intent descriptions compete, so unsupported-domain descriptors provide rejection evidence.
Recreate five-seed explicit-unknown transfer classifiers on original filtered train splits, excluding held-out supported intents; C selected on known validation plus unsupported validation, as earlier. Add semantic rescue only when classifier predicts unknown: nearest description must belong to a supported domain and pass cosine-strength .35/.45/.55/.65/.75 and known-vs-unknown margin -.05/0/.05/.1/.15. Select rescue configuration on known validation only, maximize coverage with>=95% accepted accuracy and>=90% unsupported rejection. No held-out examples calibrate rescue. Compare original classifier and rescue on identical held-out-intent tests; also monitor false unsupported acceptance. Descriptor strings and schema frozen before test. Query features are reused frozen pertext. Save every validation choice, descriptor and failure. This is additional prior information and encoder cost, not a same-information comparison with lexical classifiers.
